Project type: Web Development Laboratory mini-project

HOW TO RUN
1. Extract the ZIP archive.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Navigate with the menu. All HTML pages share style.css and app.js.

PAGES INCLUDED
- index.html — Home / project overview
- farm-info.html — Farm dashboard and plot overview
- advisory.html — Moisture and rainfall based irrigation rule demo
- gallery.html — Farm image gallery
- plot-map.html — Schematic plot layout (not GPS accurate)
- irrigation-table.html — Sensor data table with search and status filter
- registration.html — Farmer and plot form with JavaScript validation
- weather.html — IMD and map links
- media.html — Multimedia learning page and video element placeholder
- heatwave-validation.html — Heat observation form with validation
- heatwave-analysis.html — Summary table, local-record refresh, CSV export
- style.css — Shared responsive visual style
- app.js — Navigation, validation, decision rules, filtering, local storage and analytics

TECHNOLOGY
HTML5, CSS3, JavaScript. External photos and Google Fonts need an internet connection; the core pages and demo interactions run locally.

LIMITATIONS
- No backend, database, live sensor, AI model, or live weather API is connected.
- Sample plot/sensor/heatwave values are illustrative.
- Successful farmer and heatwave form records are stored in the browser's localStorage on the current device only.
- Irrigation and heatwave rules are simplified classroom demonstrations and are not professional agricultural/meteorological advice.
- The video element is a placeholder; add your own legally usable MP4 file at assets/farm-intro.mp4 to play a video.

DESIGN NOTE
This project follows the general multi-page structure and coursework features seen in the provided reference project, but uses a distinct TerraFlow identity, fresh layouts, different copy, and independently written HTML/CSS/JavaScript.
